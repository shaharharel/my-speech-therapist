# Lihi's Assistant - מערכת טיפול בדיבור לילדים 🎯

מערכת AI מתקדמת ליצירת תכניות טיפול בדיבור מותאמות אישית לילדים, המשלבת צוות רב-מקצועי וירטואלי.

## 🌟 תכונות עיקריות

- **צוות רב-מקצועי**: 5 מטפלים וירטואליים (קלינאית תקשורת, מרפאה בעיסוק, מטפלת התנהגותית, פסיכולוגית ילדים, מומחית חינוך מיוחד)
- **ניתוח מקיף**: כל מטפל מנתח את המקרה מהפרספקטיבה המקצועית שלו
- **דוחות מפורטים**: יצירת דוח Word מקיף (3+ עמודים) בעברית
- **ממשק משתמש מתקדם**: ממשק ווב ידידותי עם עיצוב מותאם לילדים
- **מעקב וניהול**: שמירת היסטוריית טיפולים וחיפוש מתקדם
- **אינטראקציה חכמה**: צ'אט לשאלות המשך על תכנית הטיפול

## 🚀 התחלה מהירה

### דרישות מערכת
- Python 3.10+
- OpenAI API key

### התקנה

1. **שכפל את הפרויקט**
```bash
git clone <repository-url>
cd my-speech-therapist
```

2. **צור סביבה וירטואלית**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. **הגדר משתני סביבה**
```bash
# צור קובץ .env
echo "OPENAI_API_KEY=your-api-key-here" > .env
echo "TAVILY_API_KEY=your-tavily-key-here" >> .env  # אופציונלי
```

### 🖥️ הפעלת הממשק הגרפי (מומלץ)

```bash
python run_server.py
```
או
```bash
python main.py
```

הדפדפן ייפתח אוטומטית ב: http://localhost:9000

### 💻 הפעלה מ-Command Line

**הפעלה בסיסית:**
```bash
python run.py patient_case="ילד בן 7 עם קושי בהגיית צלילים"
```

**מצב דיבאג (מהיר וזול):**
```bash
python launch.py debug
```

**עם מספר מטופל:**
```bash
python run.py patient_id=123456 patient_case="ילדה בת 5 עם איחור שפתי"
```

## 📱 שימוש בממשק הגרפי

### דף הבית
1. הזן מספר זיהוי מטופל (6-9 ספרות)
2. תאר את המקרה בפירוט בשדה "תיאור המקרה"
3. סמן "בדוק טיפולים קודמים" לבדיקה אוטומטית
4. לחץ "צור תכנית טיפול"

### דף הדוח
- **דוח משולב**: תכנית הטיפול המלאה
- **ניתוחי צוות**: לחץ על כל מטפל לצפייה בניתוח האישי
- **שאלות ומעקב**: שאל שאלות על התכנית בצ'אט
- **הורדה והדפסה**: הורד כ-Word או הדפס ישירות

### טיפולים קודמים
- חיפוש לפי מספר מטופל
- סינון לפי תאריך
- צפייה בדוחות קיימים
- שכפול טיפולים

## 🛠️ הגדרות מתקדמות

### קונפיגורציות זמינות
- `config.yaml` - הגדרות ברירת מחדל
- `config_debug.yaml` - מצב פיתוח (GPT-3.5)
- `config_production.yaml` - מצב ייצור

### שינוי הגדרות בזמן ריצה
```bash
python run.py llm.temperature=0.8 output.save_to_file=false
```
